## How to Use This Log

**Self-report entries** are prefixed with `[SR]` — Matteo explicitly stated his state.
**Observed entries** are prefixed with `[OB]` — Claude inferred state from language, behaviour, or context.
**TRT entries** are prefixed with `[TRT]` — testosterone injection dates and cycle notes.
**Event entries** are prefixed with `[EV]` — significant events that may affect state (sleep, conflict, wins, setbacks).

Each entry follows the format:
```
### YYYY-MM-DD | Time (if known)
**Type:** [SR] / [OB] / [TRT] / [EV]
**Energy:** Low / Medium / High (if assessable)
**Mood:** 1-word descriptor
**Notes:** Freeform observations
```
