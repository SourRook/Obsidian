## Vault Architecture Principles

**Folders are categories; links are connections.** The folder structure answers "what kind of thing is this?" The Obsidian link graph answers "what is this connected to?" Keep folders simple and stable; let the link network grow organically.

**The vault structure:**
```
00_Inbox/       — Quick capture, unsorted notes
01_Daily/       — Reflections, tasks, mood log, prompt log
02_Domains/     — Ongoing life areas: Health, Ideas, Learning, People
03_Projects/    — Finite work with clear outcomes
04_Knowledge/   — External reference material (papers, methods, techniques)
05_Goals/       — Life goals (layered: cosmic → this week)
06_Outputs/     — Finished deliverables
07_System/      — Governance, context hub, functions, preferences
08_Templates/   — Reusable templates
09_Archive/     — Completed or inactive material
```
